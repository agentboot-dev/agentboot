# Support

Thanks for using AgentBoot. Here's how to get help.

## Documentation first

Most questions are answered in the docs at **[agentboot.dev](https://agentboot.dev)**:

- [Getting started](https://agentboot.dev/docs/getting-started)
- [CLI reference](https://agentboot.dev/docs/cli-reference)
- [Troubleshooting](https://agentboot.dev/docs/troubleshooting)
- [Glossary](https://agentboot.dev/docs/glossary)

## Questions and bugs

- **Found a bug or have a feature request?** Open an
  [issue](https://github.com/agentboot-dev/agentboot/issues) using the relevant
  template.
- **Not sure if it's a bug?** Open an issue anyway and describe what you expected
  versus what happened — include your AgentBoot version (`agentboot --version`),
  Node version, and platform.

## Security

Please do **not** report security vulnerabilities in public issues. See
[SECURITY.md](SECURITY.md) for the private disclosure process.

## Scope and response expectations

AgentBoot is maintained as an open-source project. Issues and pull requests are
reviewed as maintainer time allows; there is no commercial support SLA. Clear,
reproducible reports get triaged fastest.
