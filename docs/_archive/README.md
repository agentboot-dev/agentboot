# Archived Docs

Documentation for features that have been cut, superseded, or removed from the
current AgentBoot surface. Kept for historical reference — **these files do not
describe shipping behavior.**

Convention: when a doc is retired, move it here (with an `ARCHIVED` banner) rather
than deleting it. This directory is excluded from the published npm package (the
`files` allowlist ships no `docs/`) and is ignored by the docs site (the leading
`_` and `draft: true` keep it out of the nav).

If a retired doc contains sensitive/non-public content, the archived copy here is
**redacted**; the unredacted original is retained privately outside this repo.

| File | Retired | Why |
|------|---------|-----|
| `marketplace.md` | 2026-07-12 (v1.0 GA prep) | The hosted marketplace/registry was cut from v1.0; commands hidden. Redacted (a monetization section was removed). |
